# Лучшие места города — анимированная карта Санкт-Петербурга

Квадратное видео для соцсетей: минималистичная чёрно-белая карта центра
Петербурга (вид сверху), на которой по очереди загораются и пульсируют красные
точки — как будто в этих местах прямо сейчас что-то происходит. Сверху —
заголовок **«Лучшие места города»** шрифтом Inter.

## Что происходит в ролике

- **0–2.6 с** — карта «проявляется» из центра города, заголовок собирается по буквам.
- **1.25–4 с** — одна за другой загораются 18 красных точек.
- **дальше** — каждая точка пульсирует в своём ритме (волны + мигание ядра),
  время от времени одно из мест «вспыхивает» крупной двойной волной:
  Новая Голландия, Дворцовая площадь, Севкабель Порт, Смольный собор.
- **весь ролик** — медленный плавный наезд камеры (×1.00 → ×1.12).

Точки стоят на реальных местах: Дворцовая площадь, Исаакиевский собор,
Спас на Крови, Петропавловская крепость, Новая Голландия, Летний сад,
Таврический сад, Смольный собор, Александро-Невская лавра, Севкабель Порт,
Эрарта, Газпром Арена, Морской фасад, Аптекарский огород, Финляндский вокзал,
Лофт Проект Этажи, Ткачи, Нарвские ворота.

## Стиль

- фон и суша — белые, вода (Финский залив, Нева, каналы) — светло-серая `#EEEEEE`;
- улицы — чёрные, толщина и прозрачность зависят от класса дороги;
- точки — красные `#FF2D20` с белой обводкой;
- заголовок — Inter Display Bold (оптический размер для заголовков), 70 px, по центру.

## Как пересобрать

```bash
pip install -r requirements.txt
python scripts/fetch_overture.py segment   # дороги
python scripts/fetch_overture.py water     # вода
python scripts/fetch_fonts.py              # Inter из Google Fonts
python scripts/prepare.py                  # проекция и обрезка -> data/prepared.pkl
python scripts/render.py video video/spb_best_places.mp4
```

Полезное для правок (всё в начале `scripts/render.py`):

- `PLACES` — список точек (название, долгота, широта, «крупная» точка или нет);
- `BURSTS` — моменты крупных вспышек;
- `CENTER`, `GROUND_W` — центр и ширина кадра на местности (в метрах);
- `DURATION`, `FPS`, `SIZE` — длительность, частота кадров, размер;
- `python scripts/render.py still 7.0 frame.png` — один кадр для проверки;
- `python scripts/render.py sheet 0.5,2,6,11.9 sheet.png` — раскадровка.

## Как это сделано

- **Данные карты** — [Overture Maps](https://overturemaps.org/) (релиз
  `2026-09-23.1`), слои `transportation/segment` и `base/water`; это данные
  OpenStreetMap. Скачиваются напрямую из публичного бакета S3, читаются только
  нужные группы строк паркет-файлов.
- **Рендер** — [Skia](https://skia.org/): каждый кадр рисуется заново в векторе
  с 2× суперсэмплингом, поэтому тонкие линии при наезде не «мерцают».
- **Текст** — HarfBuzz (кернинг) + Inter.
- **Кодирование** — ffmpeg / libx264.

Данные карты © участники OpenStreetMap (лицензия ODbL), поэтому в правом нижнем
углу видео есть маленькая подпись «© OpenStreetMap contributors» — её требует
лицензия при публикации.
