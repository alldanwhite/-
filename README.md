# Лучшие места города — анимированная карта Санкт-Петербурга

Бесшовная зацикленная анимация (гифка) для соцсетей и мессенджеров:
минималистичная чёрно-белая карта центра Петербурга (вид сверху), по которой
рассыпаны **217 красных точек**. Они мигают — гаснут и снова загораются, как будто
в этих местах прямо сейчас что-то происходит. Сверху — заголовок
**«Лучшие места города»** шрифтом Inter. Подписей у точек нет, звука нет.

## Как устроена анимация

- **Карта статична**, двигаются только точки — поэтому гифка лёгкая и чёткая.
- **Точки стоят на реальных местах**: кафе, кофейни, бары, рестораны, музеи,
  галереи, театры, концертные площадки, парки, исторические места (данные
  Overture Maps). Поэтому в центре их много, к окраинам меньше. Между точками
  не меньше 37 px, в воду и под заголовок они не попадают.
- **Три размера точек**: 19 крупных — на главных достопримечательностях, от них
  расходятся широкие двойные волны; четверть остальных — средние, с небольшой
  волной; остальные — маленькие.
- **Мигание**: точка горит, за 0.1 с гаснет, 0.16 с остаётся тёмной и за 0.1 с
  загорается снова с лёгким «толчком»; от крупных и средних точек при включении
  расходится волна. Каждая точка мигает 1–4 раза за цикл, фазы случайные, поэтому
  по всей карте постоянно что-то мигает.
- **Бесшовная петля**: цикл 4 с, все ритмы укладываются в него целое число раз,
  поэтому последний кадр плавно переходит в первый. Проверено на готовых файлах:
  разница «последний кадр → первый» такая же, как между любыми соседними кадрами.
  GIF сжат без потерь (`gifsicle -O3`, палитра 128 цветов): при сжатии с потерями
  ошибки копятся к концу цикла, и на стыке было бы видно «моргание».

## Стиль

- фон и суша — белые, вода (Финский залив, Нева, каналы) — светло-серая `#EEEEEE`;
- улицы — чёрные, толщина и прозрачность зависят от класса дороги;
- точки — красные `#FF2D20` с белой обводкой;
- заголовок — Inter Display Bold (оптический размер для заголовков), 70 px, по центру.

## Как пересобрать

```bash
pip install -r requirements.txt            # и gifsicle из пакетов системы: apt install gifsicle
python scripts/fetch_overture.py segment water place   # дороги, вода, места
python scripts/fetch_fonts.py              # Inter из Google Fonts
python scripts/prepare.py                  # проекция и обрезка -> data/prepared.pkl
python scripts/render.py video video/spb_best_places.mp4
python scripts/render.py gif   video/spb_best_places.gif --size=720
python scripts/render.py gif   video/spb_best_places_1080.gif --size=1080
python scripts/render.py still 1.0 video/cover.png
```

Что можно поменять (всё в начале `scripts/render.py`):

- `DOT_SPACING` — плотность точек: меньше значение → больше точек;
- `BLINK_OUT`, `BLINK_OFF`, `BLINK_IN` — как быстро точка гаснет, сколько остаётся тёмной и как быстро загорается; `LOOP` — длина цикла;
- `LANDMARKS` — где стоят крупные точки;
- `RED`, `INK`, `WATER` — цвета;
- `CENTER`, `GROUND_W` — центр и ширина кадра на местности (в метрах);
- `python scripts/render.py sheet 0,1,2,3 sheet.png` — раскадровка для проверки.

## Как это сделано

- **Данные** — [Overture Maps](https://overturemaps.org/) (релиз `2026-09-23.1`):
  `transportation/segment` (улицы), `base/water` (вода), `places/place` (места).
  Скачиваются из публичного бакета S3, читаются только нужные группы строк
  паркет-файлов.
- **Рендер** — [Skia](https://skia.org/): карта рисуется один раз в векторе
  с 2× суперсэмплингом, точки — заново в каждом кадре.
- **Текст** — HarfBuzz (кернинг) + Inter.
- **Кодирование** — ffmpeg (libx264 для MP4, палитра для GIF) + gifsicle.

Данные карты © участники OpenStreetMap (лицензия ODbL), поэтому в правом нижнем
углу есть маленькая подпись «© OpenStreetMap contributors» — её требует лицензия
